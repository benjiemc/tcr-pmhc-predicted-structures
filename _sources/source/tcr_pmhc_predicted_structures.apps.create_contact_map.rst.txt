tcr_pmhc_predicted_structures.apps.create_contact_map
=====================================================
.. code-block:: text

   usage: python -m tcr_pmhc_predicted_structures.apps.create_contact_map
          [-h] --output OUTPUT [--cutoff-distance CUTOFF_DISTANCE]
          [--even-offset-side {left,right}]
          [--log-level {debug,info,warning,error}] [--log-file LOG_FILE]
          structure
   
   Create contact map between a TCR and pMHC.
   
   options:
     -h, --help            show this help message and exit
     --cutoff-distance CUTOFF_DISTANCE
                           maximum distance to consider a contact (Default: 5.0
                           Å)
     --even-offset-side {left,right}
                           offset side when relative_pos_centre is selected
                           (Default: 'left')
   
   Inputs:
     structure             path to the input structure
   
   Output:
     --output OUTPUT, -o OUTPUT
                           path to output CSV
   
   Logging:
     Options for logging
   
     --log-level {debug,info,warning,error}
                           Level to log messages at (Default: 'warning')
     --log-file LOG_FILE   File to output logs (default is to write to stderr)
