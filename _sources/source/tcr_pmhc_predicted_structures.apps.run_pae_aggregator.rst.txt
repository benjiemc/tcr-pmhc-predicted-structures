tcr_pmhc_predicted_structures.apps.run_pae_aggregator
=====================================================
.. code-block:: text

   usage: python -m tcr_pmhc_predicted_structures.apps.run_pae_aggregator
          [-h] [--mode {untrained,evaluation,run}] --paes PAES [--model MODEL]
          --output OUTPUT [--log-level {debug,info,warning,error}]
          [--log-file LOG_FILE]
   
   Run PAEAggregator model on predictions.
   
   options:
     -h, --help            show this help message and exit
     --mode {untrained,evaluation,run}
                           prediction mode (Default: 'run')
   
   Inputs:
     --paes PAES           path to pae dataset
     --model MODEL         path to model
   
   Outputs:
     --output OUTPUT, -o OUTPUT
                           path to output predictions in csv format
   
   Logging:
     Options for logging
   
     --log-level {debug,info,warning,error}
                           Level to log messages at (Default: 'warning')
     --log-file LOG_FILE   File to output logs (default is to write to stderr)
