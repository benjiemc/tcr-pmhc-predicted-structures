tcr_pmhc_predicted_structures.apps.create_data_splits
=====================================================
.. code-block:: text

   usage: python -m tcr_pmhc_predicted_structures.apps.create_data_splits
          [-h] --output OUTPUT [--seed SEED]
          [--negative-proportion NEGATIVE_PROPORTION] [--num-folds NUM_FOLDS]
          [--split-type {random,tcr,peptide,pMHC,levenshtein}]
          [--split-distance SPLIT_DISTANCE]
          [--split-entities {cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo} [{cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo} ...]]
          [--distances DISTANCES] [--log-level {debug,info,warning,error}]
          [--log-file LOG_FILE]
          input_data
   
   Create splits in the data and shuffle entries to create negative data.
   
   Required columns:
   
       - cdr1_alpha
       - cdr2_alpha
       - cdr3_alpha
       - cdr1_beta
       - cdr2_beta
       - cdr3_beta
       - peptide
       - mhc_pseudo
   
   positional arguments:
     input_data            path to the input csv file
   
   options:
     -h, --help            show this help message and exit
     --output OUTPUT, -o OUTPUT
                           path to output csv file with the annotated sequences
     --seed SEED           random seed for data splitting
   
   Data:
     --negative-proportion NEGATIVE_PROPORTION
                           ratio of positives to negatives by randomly sampling
                           the background for the negatives (Default: 5, meaning
                           5 times more negatives than positives)
     --num-folds NUM_FOLDS
                           Number of folds to create in the dataset (Default: 5)
     --split-type {random,tcr,peptide,pMHC,levenshtein}
                           Method to partition data between folds (Default:
                           'pMHC'). 'random' means to randomly shuffle data
                           between folds, 'tcr' means no TCRs are shared across
                           folds, 'peptide' means to ensure no peptides are
                           shared across folds, 'pMHC' means that no peptides or
                           MHCs (based on pseudo sequence) are shared across
                           folds, and 'levenshtein' means to use a levenshtein
                           distance to separate data points between folds (more
                           parameters below).
     --split-distance SPLIT_DISTANCE
                           If using a 'levenshtein' split, the mimimum distance
                           between data points in two different folds (Default:
                           6).
     --split-entities {cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo} [{cdr1_alpha,cdr2_alpha,cdr3_alpha,cdr1_beta,cdr2_beta,cdr3_beta,peptide,mhc_pseudo} ...]
                           If using a 'levenshtein' split, the entities to
                           consider as part of the split.
     --distances DISTANCES
                           If using a 'levenshtein' split, the path to an hdf5
                           file containing the distances between each type of
                           entity considered.
   
   Logging:
     Options for logging
   
     --log-level {debug,info,warning,error}
                           Level to log messages at (Default: 'warning')
     --log-file LOG_FILE   File to output logs (default is to write to stderr)
