tcr_pmhc_predicted_structures.confidence_scores.compute_alpha_bridge_scores(sequences: ndarray, chain_ids: ndarray, sequence_ids: ndarray, insert_codes: ndarray, plddt: ndarray, pae: ndarray, *, mhc_type: str, atom_level_plddt: bool = True, portion: str = 'all') → ndarray

Compute AlphaBridge score.

AlphaBridge is described in AlphaBridge: tools for the analysis of predicted macromolecular complexes.

Parameters:

  • sequences – 1D array of length num_residues of one letter amino acid codes for MHC chain 1, MHC chain 2, peptide, TCR alpha chain, and TCR beta chain

  • chain_ids – 1D array of length num_residues of chain ids. The MHC chain 1 should be ‘A’, the MHC chain 2 should be ‘B’, the peptide should be ‘C’, the TCR alpha chain should be ‘D’, and the TCR beta chain should be ‘E’.

  • sequence_ids – 1D array of length num_residues of sequence ids for each residue in IMGT numbering format for the TCR:pMHC chains

  • insert_codes – 1D array of length num_residues of insert codes for each residue in IMGT numbering format for the TCR:pMHC chains. Blank insert codes are represented as empty strings (‘’).

  • plddt – 1D array of length num_atoms if atom_level_plddt is True, or else of length num_residues with the plddt scores for each token

  • pae – 2D array of shape num_residues x num_residues of the PAE score for each pairwise residue combination

  • mhc_type – either ‘MH1’ for class I TCR:pMHC complexes or ‘MH2’ for class II TCR:pMHC complexes

  • atom_level_plddt – flag to say if the resolution of the plddt array is at atom level (True) or residue level (False)

  • portion – either ‘all’, ‘cropped’, or ‘binding’ to consider different portions of the structure

Returns:

a 2D array of shape num_selected_residues x num_selected_residues with the AlphaBridge score computed for each pairwise residue combination
