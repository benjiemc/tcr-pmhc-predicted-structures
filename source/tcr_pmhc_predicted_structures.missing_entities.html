tcr_pmhc_predicted_structures.missing_entities.annotate_with_missing_entities(structure_df: DataFrame, missing_residues: list[dict], missing_atoms: list[dict]) → DataFrame

Add the missing entities information to the structure data frame.

This function does not modify the original data frame. There is a new boolean column called ‘missing’ created in the output data frame. The atom numbering may change if space was not left for the missing atoms in the original PDB structure.

Parameters:

  • structure_df – pandas data frame with structure information

  • missing_residues – missing residue information taken from PDB header

  • missing_atoms – missing atom information taken from PBD header

Returns:

new data frame with filled out missing residues and atoms with an additional column called ‘missing’
